# Inline expected output

**362 of 561 collected tests** have a fixed, nonempty output expectation in
[tests/test_compiler.py](tests/test_compiler.py). This is one checkbox per test,
including tests with several output comparisons or subtests.

- 139 compare stdout or terminal output only.
- 156 compare stderr only.
- 67 compare both streams.

The 183 snippet tests already read paired `.stdout` fixtures. This checklist
focuses on inline nonempty text and bytes. Empty-stream checks, structured
JSON assertions, regular expressions and expectations derived entirely from
the host or the input stay in Python.

- **exact** means compare the same stream, lines or terminal chunk byte for
  byte or as text, as the test already does.
- **fragment** means preserve the existing containment, prefix or suffix
  check. Several fragments may need separate fixtures.
- **interpolated** flags output assembled with values such as source paths,
  expected error text from a case table or a runtime value. Review which
  parts can become fixture text. Keep the existing location and value checks.
- **PTY** flags a terminal transcript. Some cases combine stdout and stderr
  or check the transcript at several points during execution.

Check off each method once its eligible expectations use `.stdout` or
`.stderr` files. Keep execution setup, exit status, and non-output
assertions in Python. Reuse existing output fixtures where they apply.
